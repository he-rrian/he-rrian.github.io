# 自动求导
对$\vec{y}=2\vec{x}^{T}\vec{x}$求导
```python
import torch
x=torch.arange(4.0,requires_grad=True)  #存放梯度，用x.grad访问y关于x的梯度
print(x)
print(x.grad)   #默认值是None 
```
tensor([0., 1., 2., 3.], requires_grad=True)

None
```python
y=2*torch.dot(x,x)  #相当于y=2*(x0^2+x1^2+x2^2+x3^2)
#对y进行反向传播，计算梯度
y.backward()
print(x.grad)   #打印梯度
```
tensor([ 0.,  4.,  8., 12.])

### 在默认情况下，会累积梯度。所以在计算下一个y对x的梯度时要清零
```python
x.grad.zero_()  #梯度清零
y=x.sum()
y.backward()
print(x.grad)   #打印梯度
```
tensor([1., 1., 1., 1.])
