# 2 线性回归模型
![alt text](image-5.png)
$$
f_{\vec{w},b}=\vec{w}\vec{x}+b
$$
> $\vec{x}$：输入<br>
$\vec{w}$和b为影响输出结果的因子，即模型参数<br>
$\vec{w}$：输入$\vec{x}$对输出的影响因数<br>
b：无输入时，对输出的影响
# 3 成本函数cost：$J(\vec{w}, b)$
用于描述$f_{\vec{w},b}=\vec{w}\vec{x}+b$和训练数据的拟合程度，衡量预测值与目标值的偏差
$$
J(\vec{w}, b)=\frac{1}{2m} \sum_{i=0}^m[f_{\vec{w},b}(x^{(i)})-y^{(i)}]^{2}
$$
>m：表示共有几组数据。$(x^{(i)}, y^{(i)})$表示第i组数据<br>
y：输入x对应的固定y<br>
$\hat{y}$：由模型中预测x的输出，y的估计值<br>
偏差：损失函数loss：$L(f_{\vec{w},b}(x^{(i)}), y^{(i)})=\frac{1}{2} [f_{\vec{w},b}(x^{(i)})-y^{(i)}]^2$（平方损失）

# 4 梯度下降
选择合适的w, b，使$J(\vec{w}, b)$最小
![alt text](image-2.png)其高度即为成本函数J。对于复杂的成本函数，梯度下降得到的会是局部最小值
$$ \left\{
\begin{aligned}
&w = w-\alpha \frac{\partial}{\partial w}J(w,b)=w-\frac{\alpha } {m}\sum_{i=0}^m[f_{\vec{w},b}(x^{(i)})-y^{(i)}] \cdot x^{(i)}\\
&b = b-\alpha \frac{\partial}{\partial b}J(w,b)=b-\frac{\alpha } {m}\sum_{i=0}^m[f_{\vec{w},b}(x^{(i)})-y^{(i)}]
\end{aligned}
\right.
$$
**需要同时更新w和b。自动求导时，每次都需要清0**

使$J(\vec{w}, b)$最小，即$\frac{\partial}{\partial w}J(w,b)=0 \text{和} \frac{\partial}{\partial b}J(w,b)=0$
## 4.1 小批量随机梯度下降
原因：计算梯度耗时久

方法：随机采样b个样本$i_1,i_2,...,i_b$来近似损失

b：批量大小
$$J(\vec{w}, b)=\frac{1}{b}\sum_{i \in I_b}L(f_{\vec{w},b}(x^{(i)}), y^{(i)})$$
$$ \left\{
\begin{aligned}
&w = w-\alpha \frac{\partial}{\partial w}J(w,b)=w-\frac{\alpha } {b}\sum_{i \in I_b}[f_{\vec{w},b}(x^{(i)})-y^{(i)}] \cdot x^{(i)}\\
&b = b-\alpha \frac{\partial}{\partial b}J(w,b)=b-\frac{\alpha } {b}\sum_{i \in I_b}[f_{\vec{w},b}(x^{(i)})-y^{(i)}]
\end{aligned}
\right.
$$

## 4.2 $\alpha$学习率
### $\alpha$过小
梯度下降缓慢
![alt text](image-3.png)
### $\alpha$过大
成本函数J反而会变大
![alt text](image-4.png)
### 选取
可能会从0.001开始取，发现过小则一步步增加，0.003，0.01，0.03等。最后选择一个大的且$J(\vec{w}, b)$不会上升的数

\end{gathered}
$$

# 6 多重线性回归的梯度下降
$$ \begin{gathered}
J(\vec{w}, b)=\frac{1}{2m} \sum_{i=0}^m[f_{\vec{w},b}(x^{(i)})-y^{(i)}]^{2} \\ 
\left\{
\begin{aligned}
&w_j = w_j-\alpha \frac{\partial}{\partial w_j}J(w_1,...,w_n,b)=w_j-\frac{\alpha} {m}\sum_{i=0}^m[f_{\vec{w},b}(x_j^{(i)})-y^{(i)}] \cdot x_j^{(i)}\\
&b = b-\alpha \frac{\partial}{\partial b}J(w,b)=b-\frac{\alpha} {m}\sum_{i=0}^m[f_{\vec{w},b}(x^{(i)})-y^{(i)}]
\end{aligned}
\right.
\end{gathered}
$$

# 7 特征缩放
不同的特征x相差量级可能会很大，使w一变化导致$J(w,b)$变化很大。将x进行缩放至同一量级

问题：压缩/解压会引入非线性和数值误差
## 7.1 均值归一化
$x \in [a,b]$，$\mu$为$x$的均值
$$\hat{x}=\frac{x-\mu}{b-a} \qquad \hat{x} \in [-1,1]$$

或者除以最大值
$$\hat{x}=\frac{x}{b} \qquad \hat{x} \in [0,1]$$
## 7.2 Z-score规范化
$\mu$为$x$的均值，$\sigma$为$x$的方差
$$\hat{x}=\frac{x-\mu}{\sigma}$$
## 7.3 自适应分段非线性对称压缩
目标：从一幅竖直条纹图（包含物体相位调制）中恢复绝对相位（俗称“解包裹”）

问题：单帧条纹图恢复的绝对相位范围非常大：
small 物体可能只有 ±30 rad；
large 物体可达 ±400 rad 甚至更高。
如果直接让网络预测弧度值，数值尺度相差几十倍，梯度极不均衡，训练会非常困难。

公式：

### 7.3.1 自适应尺度选择
根据样本相位范围选择的尺度因子s（scale）

| 相位范围 | scale | 目的 |
| :----: | :----: | :----: |
| < 100 rad | 250 | 小相位压缩后不至过小，保留精细特征 |
| 100 ~ 300 rad | 500 | 中等范围 |
| > 300 rad | 800 | 大相位压缩后仍能在 [0, 1] 区间 |

### 7.3.2 压缩公式
**针对单个像素点压缩**

给定真实相位$\phi$（弧度）

计算样本的相位范围$phase\_range = \phi_{max}-\phi_{min}$

压缩后的值$\hat{\phi}$
$$ 
\begin{gathered}
\hat{\phi}=\left\{
\begin{aligned}
&\frac{\phi}{s}, & & {|\phi|<10}\\
&sign(\phi) \cdot \sqrt{\frac{|\phi|}{s}},& & {|\phi|\geq10}
\end{aligned}
\right.
\end{gathered}
$$
得到$\phi$符号：$sign(\phi)$<br>
>例子：<br>
&emsp;    small样本，s=250，其中一个像素点$\phi=5$ rad < 10 rad，进入线性区 -> 压缩后：$5/250=0.02$<br>
&emsp;    large样本，s=800，其中一个像素点$\phi=-400$ rad $\geq$ 10 rad，进入平方根区 -> 压缩后：$-\sqrt{400/800} \approx -0.707$<br>

### 7.3.2 解压公式
给定压缩值$\hat{\phi}$

计算压缩域下的阈值$T_{comp}=\frac{10}{s}$

恢复值$\phi$
$$ 
\begin{gathered}
\phi=\left\{
\begin{aligned}
&\hat{\phi} \cdot s, & & {|\hat{\phi}| < T_{comp}}\\
&sign(\hat{\phi}) \cdot (\hat{\phi})^2 \cdot s,& & {|\hat{\phi}| \geq T_{comp}}
\end{aligned}
\right.
\end{gathered}
$$
>例子：
&emsp;    large样本，s=800，$\hat{\phi}=0.707$，$T_{comp}=10/800=0.0125$ < 0.707，$\phi=0.707^2 \times 800=400$ rad

## 10.1 构造数据集
随机生成x和噪声
```python
def synthetic_data(w, b, num_examples):     #num_examples样本量
    """生成y=Xw+b+噪声"""
    """
    根据指定的均值和标准差生成张量
    torch.normal(mean=0.0, std=1.0, size=(num_examples, len(w)))
    size: 输出张量的形状（当 mean 和 std 为标量时需要指定）
    """
    X = torch.normal(0, 1, (num_examples, len(w)))  
    
    y = torch.matmul(X, w) + b
    y += torch.normal(0, 0.01, y.shape) #加入噪音
    return X, y.reshape((-1, 1))        
    #将数组重塑为一列，使用-1作为行数时，NumPy会自动计算出适合的行数，以确保总元素数量不变。 

true_w = torch.tensor([2, -3.4])   #真实的w
true_b = 4.2                       #真实的b
features, labels = synthetic_data(true_w, true_b, 1000)
```

## 10.2 生成小批量用于生成近似损失
接收批量大小、特征和标签
生成一个大小为batch_size的小批量
```python
def data_iter(batch_size, features, labels):
    # 读取样本行标号，打乱标号，按照标号读取数据，即随机读取数据
    num_examples = len(features)
    indices = list(range(num_examples))
    # 这些样本是随机读取的，没有特定的顺序
    random.shuffle(indices)

    #生成range(0, num_examples, batch_size)组，大小为batch_size的小批量
    for i in range(0, num_examples, batch_size):        
        batch_indices = torch.tensor(indices[i:min(i + batch_size, num_examples)])
        yield features[batch_indices], labels[batch_indices]        
        #生成一个生成器（generator）对象，可以使用for循环或者调用next()方法遍历生成器对象来提取结果
```
>输出方法1：<br>
for X, y in data_iter(batch_size, features, labels):<br>
&emsp;     print(X, '\n', y)<br>
&emsp;     break;

>输出方法2：<br>
data = data_iter(batch_size, features, labels)<br>
next(data)  #多次运行当前代码可把多组小批量依次提取出

## 10.3 定义模型
$$\vec{y}=\vec{x}\vec{w}+b$$
```python
def linreg(X, w, b):
    """ 线性回归模型 """
    return torch.matmul(X, w) + b
```

## 10.4 定义损失函数
$$L(f_{\vec{w},b}(x^{(i)}), y^{(i)})=\frac{1}{2} [f_{\vec{w},b}(x^{(i)})-y^{(i)}]^2$$
```python
def squared_loss(y_hat, y):
    """ 均方损失 """
    return (y.reshape(y_hat.shape) - y_hat) ** 2 / 2    
    #y.reshape(y_hat.shape)可能一个行向量一个列向量。统一
```

## 10.5 定义梯度下降算法
小批量随机梯度下降
$$ \left\{
\begin{aligned}
&w = w-\alpha \frac{\partial}{\partial w}J(w,b)=w-\frac{\alpha } {b}\sum_{i \in I_b}[f_{\vec{w},b}(x^{(i)})-y^{(i)}] \cdot x^{(i)}\\
&b = b-\alpha \frac{\partial}{\partial b}J(w,b)=b-\frac{\alpha } {b}\sum_{i \in I_b}[f_{\vec{w},b}(x^{(i)})-y^{(i)}]
\end{aligned}
\right.
$$
```python
#给定参数params:是个list:[w,b]; lr学习率
def sgd(params, lr, batch_size):    
    """ 小批量随机梯度下降 """
    #临时关闭梯度计算。在更新的时候不要参与梯度计算
    with torch.no_grad():   
        for param in params:
            param -= lr * param.grad / batch_size
            param.grad.zero_()  #梯度清零
```

## 10.6 开始训练
```python
# 超参数：人为设定的参数
r = 0.03               #学习率
num_epochs = 3          #训练次数
batch_size = 10

net = linreg            #线性回归模型 
loss = squared_loss     #损失函数

# 定义参数w, b
w = torch.normal(0, 0.01, size=(2,1), requires_grad=True)
b = torch.zeros(1, requires_grad=True)

for epoch in range(num_epochs):
    #生成小批量X, y
    for X, y in data_iter(batch_size, features, labels):        
        l = loss(net(X, w, b), y)
        #因为l的形状是(batch_size, 1)，不是一个标量。将所有损失相加，即为成本函数
        l.sum().backward()  # 计算梯度
        sgd([w, b], lr , batch_size)    #使用参数的梯度更新
    with torch.no_grad():
        tran_l = loss(net(features, w, b), labels)                  #对于整个数据集计算损失
        print(f'epoch {epoch + 1}, loss {float(tran_l.mean()):f}')  #f"{表达式:格式说明符}"，:f（默认6位小数）
```
